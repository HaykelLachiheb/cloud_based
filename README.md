# Smart Waste Management Platform

This project is a cloud-based platform for efficient urban waste management, featuring:
- Citizen reporting of full/overflowing bins
- City dashboard for monitoring and analytics
- Optimized collection routes
- Scalable, secure, and ready for cloud deployment

## Structure
- `frontend/` — React app (Vite, Material UI)
- `backend/` — Node.js/Express API (JWT, MongoDB)
- `docs/` — Documentation
- `tests/` — Test suites
- `infrastructure/` — Docker, CI/CD, deployment configs

See ARCHITECTURE.md and RESEARCH.md for details.
